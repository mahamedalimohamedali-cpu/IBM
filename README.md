# IBM_Calc

## Overview
IBM_Calc is a lightweight Windows desktop application designed to calculate Body Mass Index (BMI) through a simple and intuitive graphical interface. The utility processes user-provided weight and height metrics to deliver immediate health-related data assessments.

## Key Features
*   **Automated BMI Calculation:** Implements a robust calculation engine that processes weight and height inputs using the standard BMI formula.
*   **Interactive Visual Feedback:** Features an event-driven UI that provides dynamic visual cues, such as interactive button highlights, to improve user experience.
*   **Low-Latency Performance:** Optimized as a standalone executable for rapid deployment and minimal resource consumption.

## Technical Stack
*   **Language:** C#
*   **Framework:** .NET Framework 3.5
*   **Interface:** Windows Forms (WinForms)
